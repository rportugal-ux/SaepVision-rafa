# SAEPVision

## Descrição
O SAEPVision é uma plataforma de compartilhamento de fotografias, desenvolvida para permitir que fotógrafos publiquem suas imagens e que usuários visualizem, pesquisem e curtam publicações.

## Objetivo
Desenvolver um sistema funcional de compartilhamento de fotografias, com cadastro, login, perfis de usuários e gerenciamento de publicações.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL

## Funcionalidades
- Cadastro de usuários e fotógrafos.
- Login e logout.
- Visualização de fotografias.
- Pesquisa de fotógrafos.
- Publicação de fotografias.
- Curtir e descurtir publicações.
- Visualização de perfis.
- Exclusão das próprias publicações.

## Banco de dados
Nome: `saepvision`

Tabelas:
- usuarios
- publicacoes
- curtidas

## Como executar o projeto
1. Instale o Node.js.
2. Configure o banco de dados MySQL.
3. Configure as informações de conexão no arquivo `.env`.
4. Abra o terminal na pasta do projeto.
5. Execute `npm install`.
6. Execute `npm start`.
7. Acesse `http://localhost:3000`.
